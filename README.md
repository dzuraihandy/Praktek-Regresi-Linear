## 🎯 Tentang Proyek
Regresi linear sederhana mempelajari hubungan linear antara satu variabel bebas ((X)) dan satu variabel terikat ((Y)). Bentuk model umumnya:

[
Y = a + bX
]

- **(Y):** variabel respons atau variabel terikat.
- **(X):** variabel prediktor atau variabel bebas.
- **(a):** intersep model.
- **(b):** koefisien kemiringan.
